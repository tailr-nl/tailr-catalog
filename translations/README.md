# Translations

One JSON file per language, for example `de.json`. The keys are the original Dutch texts of the admin environment, and the values are the translation. Keep placeholders such as `{name}` unchanged.

```json
{
  "$schema": "../schemas/translation.json",
  "name": "Deutsch",
  "Koppelingen": "Verbindungen"
}
```

In Tailr Core, *Catalogue → Translations* lets an administrator download the missing texts for a language and upload the result. English is built into Tailr Core.
